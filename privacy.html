clipbot Privacy Policy

Last updated: November 21, 2026

This Privacy Policy explains how clipbot accesses, uses, stores, and protects information obtained through Google OAuth and YouTube API Services.

1. Purpose of clipbot

clipbot is a personal video automation application used by its owner to prepare, upload, and monitor short-form video content on the owner's YouTube channel.

2. Google user data accessed

After explicit authorization through Google OAuth 2.0, clipbot may access the following information through YouTube API Services:

  • Authorization credentials required to access the authorized YouTube account.
  • Basic YouTube channel information.
  • Videos uploaded or managed through the application.
  • Basic video information and statistics, including video IDs and view counts.

clipbot does not access Google passwords.

3. How Google user data is used

The data is used only to provide clipbot's core functionality:

  • Uploading approved videos to the authorized YouTube channel.
  • Retrieving information about uploaded videos.
  • Retrieving basic video statistics for private reporting.

Google user data is not used for advertising or user profiling.

4. Data storage and security

OAuth credentials required for persistent authorization are stored on the application owner's private server. Access to the server is restricted to the application owner.

Reasonable technical security measures are used to protect credentials and other stored information against unauthorized access.

5. Data sharing

clipbot does not sell Google user data.

clipbot does not transfer or disclose Google user data to third parties except when required to provide the requested application functionality, comply with applicable law, or protect the security of the service.

6. Data retention

Google OAuth authorization information is retained only while required to operate the application. Authorization can be revoked by the user at any time.
